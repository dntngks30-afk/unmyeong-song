# PR01 Execution Log - Auth Gate + 라우팅 정리

## 목표
- 로그인 전 `(tabs)` 접근 차단.
- 루트 라우팅을 auth 중심으로 고정.
- `(auth)/login`, `(auth)/signup` 기본 라우트 구성.

## 변경 파일
- `app/_layout.tsx`
- `app/(auth)/_layout.tsx`
- `app/(auth)/login.tsx`
- `app/(auth)/signup.tsx`
- `package.json`
- `package-lock.json`

## 구현 요약
- 루트 레이아웃에서 `supabase.auth.getSession()` + `onAuthStateChange`로 세션 상태 추적.
- 세션 없으면 `(auth)/login`으로 강제 리다이렉트.
- 세션은 있으나 프로필이 없으면 `(auth)/signup`으로 유도.
- 로그인 완료 상태에서는 `(tabs)/home`으로 유도.
- `main=expo-router/entry`는 유지하고, 인증 라우트 그룹을 별도 분리.

## 검증
- 타입체크: `npx tsc --noEmit`
  - FE 경로 기준 신규 오류 없음.
  - 기존 Supabase Edge Function(Deno 타입/`.ts` import) 관련 오류는 잔존.
- 수동 스모크:
  - 로컬 세션 부재 시 로그인 화면 노출 로직 반영.
  - 탭 직접 진입 시 auth 리다이렉트 로직 반영.

## 비고
- `@supabase/supabase-js` 패키지를 의존성에 추가해 FE auth/session 코드 정합성을 맞춤.
