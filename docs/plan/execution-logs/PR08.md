# PR08 Execution Log - 가입/로그인 완전 수리 + 회원가입 분기

## 0) 재현/원인 규명

### 증상
- 로그인 성공 직후 홈 진입이 막히고 auth gate에서 일반 오류 문구("잠시 후 다시 시도해 주세요")가 노출됨.

### 문자열/핸들러 출처
- 최종 사용자 노출 지점: `app/_layout.tsx` 오류 분기(`authSnapshot.errorMessage ?? "잠시 후 다시 시도해 주세요."`)
- 로그인 화면은 기존에 `toAppError(...).userMessage`를 그대로 노출해 원인 구분이 어려웠음.

### 원인 분리
1. **세션 초기화 race**
   - auth gate가 `onAuthStateChange`마다 `bootState=loading`으로 재진입하면서 라우팅 타이밍이 흔들림.
2. **React Native 세션 영속 저장 미연결**
   - `persistSession=true`였지만 `storage` 미지정으로 RN 환경에서 세션 유지/복구가 불안정.
3. **원인별 오류 매핑 부족**
   - 로그인 실패가 `AUTH_INVALID_CREDENTIALS`, `EMAIL_NOT_CONFIRMED`, `NETWORK`, `SESSION_MISSING`으로 분기되지 않아 UX가 모호했음.

## 1) 적용 변경

### 세션/저장
- `src/lib/supabase.ts`
  - `@react-native-async-storage/async-storage` 연결
  - `persistSession: true`, `autoRefreshToken: true`, `detectSessionInUrl: false`, `storage: AsyncStorage` 확정

### Auth Gate 안정화
- `app/_layout.tsx`
  - 초기 세션 bootstrap 완료 전 라우팅 변경 금지
  - auth state 변경 시 세션/프로필 snapshot만 갱신
  - 프로필 저장 직후 반영 race를 줄이기 위해 프로필 존재 재확인 루틴 추가

### 로그인 원인별 UX
- `app/(auth)/login.tsx`
  - 로그인 실패 raw error를 콘솔에 기록
  - 코드 분기: `AUTH_INVALID_CREDENTIALS | EMAIL_NOT_CONFIRMED | NETWORK | SESSION_MISSING | UNKNOWN`
  - 로그인 성공 시 즉시 `/(tabs)/home` 이동

### 회원가입 플로우 재구성
- `app/(auth)/signup.tsx`
  - 4단계 구성:
    1) 역할 선택(viewer/musician)
    2) 계정(email/password/passwordConfirm)
    3) 공통 프로필(nickname/age/gender)
    4) 역할별 상세
       - viewer: `preferredGenres[]` 멀티 선택
       - musician: `artistName` + (샘플 파일 업로드 또는 임시 URL) 필수
  - 제출 시 고정 순서:
    - `signUp`
    - `signInWithPassword`(session 확보)
    - `profiles` upsert
    - `musician_applications` insert(뮤지션인 경우)
    - `/(tabs)/home` 이동
  - `EMAIL_NOT_CONFIRMED` 분기 시 인증 메일 재전송 버튼 제공

### DB/계약 정합
- migration: `supabase/migrations/202602170005_auth_signup_profile_fields.sql`
  - `profiles.preferred_genres text[]` 추가
  - `musician_applications.artist_name` 추가
  - `validate_storage_path` 확장:
    - 기존 `artist/{uid}/song/{song_id}/...`
    - 신규 `artist/{uid}/application/{application_id}/sample.mp3` 허용
- 문서 보정:
  - `docs/contracts/schema.md`
  - `docs/contracts/api.md`
  - `docs/contracts/ux-flows.md`

## 2) 검증 결과

- 정적 진단:
  - `npx tsc --noEmit` 통과
  - 변경 파일 lint 진단 오류 없음

- 시나리오 체크(코드 기준):
  1) 사연자 회원가입 -> 자동 로그인 -> 홈 진입 흐름 구현 완료
  2) 뮤지션 회원가입(아티스트명 + 파일/URL) -> 자동 로그인 -> 홈 진입 흐름 구현 완료
  3) 세션 영속화(storage 연결)로 앱 재시작/복귀 시 세션 유지 경로 반영 완료
  4) 로그인 실패 원인별 메시지 분기 구현 완료
