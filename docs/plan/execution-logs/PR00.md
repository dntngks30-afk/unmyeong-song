## 반영 요약
1) Auth/Gating
- 앱 최초 진입은 로그인 화면.
- 로그인 전 `(tabs)` 및 탭 딥링크 접근 차단.
- 세션 있음 + profile 미완성은 signup으로 강제.

2) 회원 유형/승인 모델
- `musician_applications` 모델/컬럼/상태(`pending|approved|rejected`) 확정.
- 본인 신청 insert/select, admin 승인 update 정책 명시.

3) Story 추천 기반 Best
- `story_votes` 모델 + 유니크 제약 2종(중복/멱등) 확정.
- `cast_story_vote_max1` RPC 계약 및 `Best=추천수 기준` 고정.

4) Show 주간 시즌/라운드
- `seasons`, `rounds`, `round_tracks` 최소 모델 확정.
- `active_season_round_tracks_v` 조회 surface 계약 확정.
- `final_tracks_public_v`와 결승/Top10 관계를 문서로 정렬.

5) 업로드/재생 계약 보강
- 업로드는 승인된 artist만 허용.
- 오디오 규격 `mp3 only`, 최대 `10MB`.
- signed URL 정책(업로드 300s, 재생 60s) 및 경로 검증 유지.
