# PR04 Execution Log - Show 시즌/라운드 + 트랙 상세 진입

## 목표
- Show 탭을 주간 시즌 라운드(예선/본선/결승) 구조로 표시.
- 라운드별 트랙 카드에서 상세 화면으로 진입.
- 상세 화면에서 재생 버튼은 PR05를 위한 스텁으로 제공.

## 변경 파일
- `features/show/api/queries.ts`
- `app/(tabs)/show.tsx`
- `app/show/[id].tsx`
- `app/_layout.tsx`

## 구현 요약
1) 데이터 조회
- `active_season_round_tracks_v` 기반 조회 함수 추가:
  - `getActiveSeasonRoundTracks()`
  - `getRoundTrackDetail(trackId)`
- 라운드 타입(`qualifier|semi|final`)과 정렬(`display_order`)을 타입으로 고정.

2) Show 탭 UI
- loading/empty/error/ready 상태머신 적용.
- 예선/본선/결승 섹션별 카드 렌더.
- 카드 클릭 시 `/show/[id]` 상세 진입.

3) 상세 화면
- 트랙 메타데이터 표시.
- `재생(PR05에서 활성화)` 버튼 스텁 추가.

## 검증
- 타입체크: `npx tsc --noEmit`
- 수동 점검:
  - 라운드 데이터 있으면 섹션별 렌더
  - 빈 데이터면 empty 문구
  - 카드 클릭 시 상세 진입

## 비고
- 재생/권한/만료 처리 로직은 PR05에서 실제 활성화 예정.
