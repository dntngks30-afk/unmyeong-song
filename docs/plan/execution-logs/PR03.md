# PR03 Execution Log - 사연 추천 + Best

## 목표
- 사연 목록/상세/작성 흐름 위에 추천 RPC와 Best(추천수 기준) 영역을 연결.
- 중복 추천/멱등 재시도/실패 메시지 처리를 표준 에러 코드로 정렬.

## 구현 요약
1) DB
- `story_votes` 테이블 추가 + 유니크 제약:
  - `unique(voter_id, story_id)`
  - `unique(voter_id, client_request_id)`
- `cast_story_vote_max1` RPC 추가:
  - 중복 추천 -> `DUPLICATE_VOTE`
  - 동일 request id -> 성공 동일응답(`idempotent_replay=true`)
- `best_stories_v` view 추가(`vote_count desc, created_at desc`)

2) FE Query/Mutation
- `getBestStories(limit<=4)` 추가.
- `castStoryVoteMax1()` 추가.
- Story 타입에 `voteCount` 추가.

3) Story UI
- Story 탭 상단에 Best 섹션(최대 4개) 추가.
- 리스트/Best 카드에 추천수 표시 및 추천 버튼 연결.
- 추천 성공/중복/기타 실패 메시지 분기 추가.

4) 작성 UX 보강
- `submit_story_rate_limited` 실패 시 retryable 에러에 대해 자동 1회 재시도.
