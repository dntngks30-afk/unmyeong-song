# PR09 실행 로그 - Auth Gate 리다이렉트 루프 수정

## 목표
- 앱 실행 시 회원가입 화면으로 자동 이동되는 문제 제거
- 로그인 성공 후 회원가입 화면으로 되돌아가는 루프 제거
- 세션 로딩 완료 후 1회 판정 방식으로 라우팅 고정

## 재현 경로
1. 앱 실행
2. 세션이 없거나 프로필이 없는 계정 상태에서 초기 라우팅 관찰
3. 로그인/회원가입 화면 전환 후 재진입 시 라우팅 관찰

## 원인 분석
- 파일: `app/_layout.tsx`
  - 문제 useEffect: `hasSession=true && hasProfile=false` 조건에서 `router.replace("/(auth)/signup")` 강제 이동
  - 영향: 프로필 생성 타이밍/상태에 따라 로그인 이후에도 전역 가드가 signup으로 덮어쓰며 루프 발생
- 파일: `app/(auth)/login.tsx`, `app/(auth)/signup.tsx`
  - 문제: 이미 세션이 있는 경우를 초기에 흡수하는 역방향 가드가 없어, auth 화면 잔류 가능성 존재

## 수정 요약
- `app/_layout.tsx`
  - 전역 Auth Gate를 세션 기반 단일 규칙으로 단순화
  - 세션 로딩 완료 전(`bootState !== "ready"`)에는 라우팅 변경 금지
  - 로딩 완료 후:
    - 세션 없음 -> `/(auth)/login`
    - 세션 있음 + auth 라우트 진입 상태 -> `/(tabs)/home`
  - signup 강제 리다이렉트 분기 완전 제거
- `app/(auth)/login.tsx`
  - 세션 로딩 상태(`loadingSession`) 추가
  - 초기 `getSession()` + `onAuthStateChange`에서 세션이 있으면 즉시 `/(tabs)/home`으로 역방향 가드
- `app/(auth)/signup.tsx`
  - 세션 로딩 상태(`loadingSession`) 추가
  - 초기 `getSession()` + `onAuthStateChange`에서 세션이 있으면 즉시 `/(tabs)/home`으로 역방향 가드
  - 기존 UX 유지: 가입 성공 시 "가입을 환영합니다" 팝업 후 login 이동
