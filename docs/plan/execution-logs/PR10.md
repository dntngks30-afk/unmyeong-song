# PR10 HOTFIX 실행 로그 - 루트 엔트리 고정(AuthGate 단일화)

## 재현
- 앱 첫 진입(`/`)에서 로그인 화면 대신 Top10 투표 화면이 렌더됨
- 일부 플로우에서 로그인/회원가입 화면 전환이 반복되어 체감상 루프 발생

## 원인(1줄)
- `app/index.tsx`가 Top10 투표 UI를 직접 렌더하고 있어 expo-router의 `/` 엔트리가 AuthGate보다 먼저 Top10 화면으로 매핑됐다.

## 수정 내용
1. `app/index.tsx`
   - Top10 투표 화면 코드 제거
   - 루트 엔트리를 인증 확인용 로딩 화면으로 교체(실제 라우팅 결정 없음)
2. `app/_layout.tsx`
   - 전역 AuthGate 단일화 유지
   - 세션 로딩 완료 전(`bootState !== "ready"`) 라우팅 변경 금지
   - 로딩 완료 후 규칙 고정:
     - session 없음 -> `/(auth)/login`
     - session 있음 -> `/(tabs)`
   - `index` 스택 화면 헤더 제거(루트 임시 화면 노출 최소화)
3. `app/(auth)/login.tsx`, `app/(auth)/signup.tsx`
   - 역방향 가드 경로를 `/(tabs)/home`에서 `/(tabs)`로 통일
   - 세션 존재 시 auth 화면 잔류 방지
