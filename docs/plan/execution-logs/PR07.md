# PR07 Execution Log - Home/My 최소 완성

## 목표
- Home 탭에 사연/곡 미리보기 섹션을 구성해 핵심 탐색 진입점을 제공.
- My 탭에 역할별 메뉴와 로그아웃 동작을 추가해 사용자 운영 흐름을 완성.

## 변경 파일
- `app/(tabs)/home.tsx`
- `app/(tabs)/my.tsx`

## 구현 요약
1) Home 탭
- `getBestStories(3)` + `getTop10Tracks()`를 병렬 조회해 미리보기 데이터 로드.
- 공통 상태머신(`loading|empty|error|ready`)을 실제 데이터 상태에 맞게 적용.
- 섹션 구성:
  - 인기 사연 미리보기(상세 `/story/[id]` 진입)
  - Top 곡 미리보기(상세 `/show/[id]` 진입)
- 각 섹션에 "더보기/이동" 버튼 제공:
  - `/(tabs)/story`, `/(tabs)/show`

2) My 탭
- 기존 제출 CTA 유지 + 승인 게이트 규칙 재사용.
- 역할별 최소 메뉴 추가:
  - 공통: 사연 작성하기(`/story/write`)
  - 관리자: 검수 메뉴(준비중 안내)
- 로그아웃 버튼 추가:
  - `supabase.auth.signOut()` 후 `/(auth)/login`으로 이동

## 검증
- lint: 변경 파일 기준 진단 오류 없음.
- 타입체크: `npx tsc --noEmit` 성공.
- 수동 체크리스트:
  - Home에서 사연/곡 미리보기 렌더 확인
  - Home 카드 탭 시 상세 이동 확인
  - My에서 로그아웃 클릭 시 로그인 화면 복귀 확인

## 비고
- Home은 "미리보기 중심" 최소 구성으로, 정렬/캐시 고도화는 후속 티켓에서 확장 가능.
